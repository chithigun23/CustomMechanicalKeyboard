# ASA plate for Bambu H2D

`bit_anchors_spacers_ASA_H2D.3mf` (open in Bambu Studio, reslice with your ASA profile if you like):
3 x T10 security Torx bit (variants A/B/C), 8 x stab anchor H1/H8, 4 x stab anchor H7, 21 x 2.5 mm spacer.
Bambu Lab H2D, 0.4 mm nozzle, Bambu ASA 270 C, Engineering Plate, 0.08 mm layers, 0.18 mm first layer (spacers land on 2.50 mm), 100% infill, 4 walls, 4 mm brim. About 1 h 11 min, 2.5 g.

`T10_security_torx_bit_plate_ABC.stl` + `make_bit.py`: the bit variants (tip 2.72 / 2.64 / 2.56 mm, hex 3.95 / 3.90 / 3.85 mm, 1.3 x 2.5 mm pin hole; pin size is a guess).
The anchors and spacers come from `3D Print Files/v2` (generated from the case/PCB geometry).
